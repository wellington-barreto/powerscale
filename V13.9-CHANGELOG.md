# POWER SCALE v13.9

## Conversão de moeda
- Troca de moeda 100% em memória: não invalida React Query, não dispara `focus`/`online` e não refaz consultas ao backend.
- Cada resposta monetária mantém um snapshot original em memória; toda projeção USD/BRL/EUR/GBP é recalculada a partir do original, evitando conversões acumuladas.
- A taxa em cache é carregada imediatamente; AwesomeAPI é atualizada em segundo plano no boot e nunca é chamada pelo clique do seletor.
- Alteração de taxa manual reprojeta apenas os dados já carregados.

## MCC / carga histórica
- Corrigido `Encontradas: 0 / Selecionadas: 0` no callback do `executeInParallel`.
- Total e quantidade selecionada são transportados no parâmetro da execução e devolvidos pelos workers.
- `POWER SCALE MCC concluído` agora só é registrado após resposta HTTP 2xx do endpoint de finalização.
- Em falha de finalização, o log informa explicitamente `NÃO finalizado`.
- A flag de carga completa só é desativada pelo backend quando todas as contas encontradas foram selecionadas, todas concluíram e não houve erros.
- A tela de Google Scripts acompanha a flag ativa a cada 5 segundos e desmarca automaticamente quando o backend confirmar a conclusão.
